## 踩坑记录
- 圆环擦除小球：strokeDashoffset 擦除终点不能 >100（dasharray 单值周期=200，offset 取模会让 dash 从圆起点露出来），应保持 100 并用 opacity 淡出盖掉浮点残留
- 内联 style="display:none" 优先级高于 CSS 类选择器：loading 圆环默认隐藏必须放 CSS，不能用内联样式
- SVG circle 的 CSS 旋转动画需 transform-origin + transform-box:view-box，否则绕左上角转

## 改动摘要

### 第四段闭合赛道动画（用户最终接受版，取代 08-12 移除的两轮失败方案）

用户贴出 anime.js 官方 motion path demo（铃鹿赛道小车 + createDrawable 描边）要求分析 → 选定方案：闭合赛道 + 圆点绕行 + 轨道描边生长 + 多形状切换。

**最终实现**（animation-lab.astro，未提交）：
1. **HTML**：`#lab-track` svg 层（lab-engine 后）+ `#lab-shape-menu` 形状菜单（lab-code-card 后）
2. **JS**（引擎段后，~120 行）：
   - `trackShapeD(shape)` 采样生成 7 种闭合 path：圆(72点,R)、椭圆(288×158)、菱形(4点)、心形(参数方程 96 点, x=16sin³t, y=13cost−5cos2t−2cos3t−cos4t, 缩放 R/17)、五角星(10 顶点, 外 R/内 0.42R, 顶部顶点起)、方形(±R×0.8)、三角(3 点等边)
   - `trackRebuild()`：每次切换清空 svg 重建轨道 path + 圆点 circle(r=8)，dasharray=L L + dashoffset=L（初始全隐藏）
   - `trackLoop(t)` 独立 rAF：4.2s 一圈，`trackProg += dt/4200`（不取模，累计用于画轨道）；圆点位置 = loopP=trackProg%1 处 getPointAtLength；切线角 = p+1 处差分 atan2 → rotate；轨道描边 `dashoffset = L×(1−min(trackProg,1))` —— **第一圈跟随圆点画满后保持完整，圆点继续绕**
   - 菜单点击：换 trackShape → trackRebuild()（重置 trackProg=0 重新画）
3. **CSS**：.lab-track（z-index 6, opacity 0）+ .lab-shape-menu（fixed 右下 right:12% bottom:calc(10%+165px)，仅第四段显示）
4. **updateProgress**：idx===3 显示 lab-track + 菜单（opacity + pointerEvents 一起切）

**用户微调**（已应用）：
- 图形整体变小 20%：`trackScale = 0.8`（R=235→188；椭圆 288→230、158→126；心形/五角星/菱形/方形/三角都经 R 派生自动跟随）
- 去除荧光：轨道 `brightness(1.42)`、圆点 `brightness(1.5)` 去掉 drop-shadow（保留提亮）

**验证**：npm run build 27 页通过（多次）；产物 dist/_astro/*.js 确认含 getPointAtLength（轨道逻辑已进打包）；grep 变量名会被压缩混淆，用字符串验证

**关键设计决策**：不用 anime 的 createMotionPath 封装（update 对象动画不可靠），用 path.getPointAtLength 自己算坐标 + 独立 rAF，和项目老规矩一致；圆点 cx/cy 直接 setAttribute 不碰 transform-box；元素极少（1 path + 1 circle）无性能风险；不做几何映射（上次失败区）

### 3. 全局点击绽开特效（BaseLayout.astro，所有页面生效）

### 4. 第六段引擎仪表盘刻度复位修复
- Bug：刻度外移+高亮只在 `active && tickLines.length`（第六段内）执行，离开第六段刻度停在最后外移位置
- 修复：改为 `if (tickLines && tickLines.length)` 无条件处理，active 分支原逻辑，else 分支复位位置+宽度/线帽
- **坑1（整体崩溃）**：tickLines 声明在 1006 行（engineSpin 之后），engineSpin 是立即执行 IIFE 首帧同步跑时 tickLines 还 undefined → `tickLines.length` 抛 TypeError 崩整个动画循环。必须 `tickLines && tickLines.length`
- **坑2（颜色竞态）**：else 分支若设固定 colors[5]（第六段色）会与 updateProgress 的"刻度颜色=当前段色"机制抢（滚动时 updateProgress 赢、停止后 engineSpin 每帧覆盖成第六段色）→ else 分支只复位位置+宽度/线帽，**不碰颜色**（颜色全交给 updateProgress）

### 5. 第七段魔方（迭代中）
- 用户需求演变：线框魔方 → **实心彩色魔方**（每方块 6 面不同色：右红/左橙/上黄/下绿/前蓝/后紫）→ **拆解-重组**（27 方块散开收拢）→ **去掉旋转/散开** → **25 个方块 + 1 骨架**
- 当前实现：骨架=中心核(r10 深灰)+6 方向十字轴(粗 7px 伸到面心方块内部)；25 方块=3×3×3 去中心(0,0,0)和背面中心(0,0,-1)(被轴尾代表)；每帧法线可见性(z>0)+方块按旋转后中心 z 画家排序；静止 30° 斜角展示
- 3D 数学：先 Rx(tiltX=-25°) 再 Ry(spinY)，正交投影只取 x/y 不缩放（cubeRotPt）
- 坑：魔方 depth 排序必须用旋转后 z（远→近画），法线可见性用旋转后法线 z>0

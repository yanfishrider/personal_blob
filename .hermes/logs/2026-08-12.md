### 第四段 composition 动画重构（删除自动动画 → 坐标系 + 曲线函数驱动）

1. **删除第四段全部自动动画**（commit 7b4846e 的 mixUpdate/mixLoop/mixBallDia 椭圆弧目标点）
   - 横线背景保留（静态菱形包络），圆球线保留静态布局

2. **圆球手动拖拽（仅 y 轴）**（第一版交互）
   - pointerdown/move/up + setPointerCapture，getScreenCTM().inverse() 坐标转换
   - cx 固定只改 cy，拖拽中显示贯穿圆的竖向虚线参考线
   - 范围限制 40~710，hover/拖拽高亮（brightness）
   - 拖拽后位置存 mixBallCur（mixBallBase 保留初始直线）

3. **自定义光标兼容**：BaseLayout 光标系统加 `data-native-cursor` 通用机制
   - 鼠标在带该属性的元素上时隐藏自定义光标，交还系统光标
   - 圆球 CSS cursor: grab/grabbing !important 覆盖全局 cursor: none !important

4. **坐标系 + 曲线函数驱动**（用户提出：逐个拖拽太麻烦 → 用坐标系操作）
   - 坐标系：原点 = 起始球 (1,1)；x 轴水平（球编号 1~38，间距 14px，基线过圆心 375）；y 轴垂直（正方向屏幕上方）
   - 球位置 = 基线点 + (f(x) - 1) × 垂直单位向量 (0,-1)
   - 函数面板（右下角代码卡片上方，仅第四段显示）：
     - 6 个函数：直线 / 正弦 / 余弦 / 椭圆弧 / 抛物线 / S曲线
     - 参数滑杆：振幅(0~200)、频率(1~4，正弦/余弦)、陡度(1~6，S曲线)
     - 复选框：函数模式（勾选禁用逐球拖拽）/ 坐标轴显示
   - 坐标轴辅助线：x 轴虚线 + 刻度(1/10/19/28/37) + 原点十字标签 (1,1) + y 轴方向短虚线

5. **背景横线 = 球线形状截面（旋转体截面）**（用户提出：把函数应用到背景横线）
   - 上轮廓 = 球线当前位置，下轮廓 = 关于基线镜像，合成闭合形状
   - 每条横线与该闭合形状求交：长度 = x 跨度 + 带宽 5
   - 效果：直线水平→矩形（上下轮廓平行等长）/贴基线→菱形包络；倾斜→X形交叉菱形；椭圆弧→椭圆；正弦→波浪胶囊；抛物线→透镜；S→腰鼓；余弦→斜椭圆

6. **直线函数线性插值 + 起点/终点Y参数**（用户提出：判断菱形还是矩形）
   - f(x) = 起点Y + (终点Y - 起点Y) * (x-1)/37
   - 面板新增起点Y/终点Y滑杆（-150~250，仅直线模式显示）

### 下午：背景横线映射 4 版迭代 → 全部被否 → 移除整个第四段

**映射思路全程失败档案（用户连续 4 次否定，最终主动要求移除）**：

1. **v1 上轮廓+对称镜像**：对称轴 = 球线两端中点 y，球线 = 图形上边，下边 = 镜像，左右闭合；水平时上下边重合给 60px 半高矩形 → 用户"不是这样"
2. **v2 端点锚定**：起点 = 图形坐标原点（横线左端对齐起点 x），终点 = 最上方横线中点；宽 = 2×|dx|、高 = |dy|（水平固定 260）→ 用户"不是这样"，给出**两套坐标系模型**：
   - 第一套坐标：球线为 X 轴，球=1 单位，原点=起点球圆心
   - 第二套坐标：容器圆心为原点；球线 → 背景图形第二象限的边，四象限对称闭合
   - 例：球线水平（两端都在 X 轴）→ 背景 = 十字；球线 30° → 背景 = 菱形且球线与菱形两边平行
3. **v3 两套坐标系四象限对称**：球线曲线 → 第二象限边（y 轴镜像+缩放）→ 四象限对称闭合图形 → 用户"为什么感觉角度不相同"
4. **v4 等比单位修复**：1 单位 = 1 球距（14px），x/y 同单位，超界整体等比缩小（角度不变）→ 用户仍放弃

**最终**：用户"算了，移除这个动画效果，太难实现且思路一直对不上" → 整个第四段全部内容移除：
- HTML：lab-mix svg + lab-fn 函数面板
- JS：382 行（mixSvg/mixEvalFn/mixApplyFn/mixUpdateLines/mixDrawAxis/拖拽/面板绑定）
- CSS：.lab-mix + .lab-fn 系列
- updateProgress 显隐逻辑

### 傍晚：网格波浪动画（anime Grid Wave 风格）→ 尝试 5 轮 → 用户放弃

**需求**：官方 demo 的 createTimeline + stagger 网格波浪替代第四段 + 形状菜单（心形/五角星等）

1. **v1 圆点 + timeline**：13×13 点阵形状裁剪 + createTimeline stagger + 边缘系数（中心大边缘小）→ 用户补充：边缘波浪小形成轮廓线条感
2. **v2 方块 + 官方 Grid Wave**：rect 方块、scale 脉冲 0→峰值→0 keyframes、onComplete 递归循环、drop-shadow 发光 → 用户"没有动画"（anime v4 函数返回 keyframes 不可靠 + CDN 依赖）
3. **v3 每元素独立 animate**：改用每元素独立 animate + 官方 keyframes 数组语法 + dist 数组 delay → 点数 13→17、方块 26→18、速率 380→550ms、延迟 90→140ms、整体缩小 250→215px、心形 scale 0.9+下移 24px、方形 0.75、颜色=第四段弧色 colors[3] #6A9622 → 用户"卡顿"
4. **v4 性能修复**：合并单 animate 实例 + 去 drop-shadow + delay 用 dist 数组 → 用户"直接卡死了"（25×25=1250 元素 CSS fill-box transform 爆掉）
5. **v5 独立 rAF + SVG attribute transform**：waveGrid 回到 17，rAF 每帧写 translate(cx cy) scale(s) translate(-cx -cy) 绕自身圆心缩放，相位=时间-距中心延迟，峰值=1+(0.35+1.05×edge-1)×(0.5-0.5cos)，5 rad/s → 用户"没有波浪涌动"（速度太慢+CDN 依赖 initWave）；提速 5 rad/s + 独立初始化（不依赖 anime CDN）

**最终**：用户"移除这个动画效果，不合适" → 整个网格波浪动画移除：
- HTML：lab-wave svg + lab-wave-shape 形状菜单
- JS：151 行（waveInShape/waveEdge/waveRebuild/wavePlay rAF/initWave）
- CSS：.lab-wave + .lab-wave-shape/.lab-ws 系列
- updateProgress 显隐（含第四段隐藏背景点阵逻辑一并删除）

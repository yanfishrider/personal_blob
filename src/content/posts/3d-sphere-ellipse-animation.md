## 缘起

动画实验室（`/animation-lab`）是一个复杂页面动画测试画布：整页固定，8 段圆弧围成圆环，每段圆弧对应一个独立的中心动画，滚轮驱动场景推进。前两段分别是「中心旋转色块」和「12 图形随机游走」，第三段要做的是——一个看起来像 3D 球的东西。

一开始的想法很朴素：让色块绕椭圆轨道旋转，多几个色块、多几层轨道，球不就出来了？结果试下来要么像纺锤，要么像扁椭球，怎么都不对。直到把原理想清楚：**人眼感知 3D 球，靠的是线条叠加出的透视关系，而不是色块本身。**

## 设计原理：球面纬线投影

球体上每一圈纬线，投影到 2D 画布都会变成椭圆：

- 球体越靠近上下两极，纬线投影出的椭圆越小、越扁；
- 赤道（正中间）的纬线最大；
- 每一条线，本质都是球面上一个纬度圈，经过透视运算转为 2D 椭圆。

把很多条这样的椭圆（大小渐变、位置错开）一圈圈画出来，线条叠加，人眼就会把它解读成一个三维球体——这就是「科技感扫描球」的常见画法，也是本页第三段的实现依据。

## 布局：20 条椭圆沿对角线排布

```
对角线 y = x（通过圆容器圆心 375,375）
20 条椭圆，索引 i = 0 ~ 19，间距 Δ12
圆心：cx = cy = 375 + (i − 9.5) × 12
```

- **最大椭圆在正中心**：半径最大的椭圆（rx ≈ 259）圆心就是圆容器的圆心，它是整个球体的「赤道」；
- **两端对称渐小**：第一个和最后一个椭圆半径缩小到一半（rx ≈ 58），其余按抛物线平滑过渡——`rx = 57.5 + 201.25 × (1 − t²)`，`t` 从 −1 到 1；
- **扁度统一 0.2**：`ry = rx × 0.2`，整体看起来像一枚倾斜的球体；
- **统一 −45° 斜向**：让整个椭圆簇带有透视倾角，避免水平排布显得呆板；
- **两端外扩、中心锚定**：以最大椭圆为锚，两侧椭圆沿对角线按比例外移（幅度 48），球体轮廓更饱满。

## 交互：滚轮驱动「画 → 保持 → 擦除」

椭圆不是静态画好，而是随滚轮进度逐条出现、逐条消失，像有一支笔在空间中勾勒球体：

```
drawP 0 ~ 1    画出（dashoffset L → 0，线条逐渐描出完整椭圆）
drawP 1 ~ 2    保持完整（闭合椭圆停住，供观察）
drawP 2 ~ 2.5  擦除（加快半圈：从起始位置开始擦，起点先消失）
drawP > 2.5    彻底消失（opacity 0，不循环）
```

- **出现时机错开**：第 i 条椭圆在段内进度 `i × 0.0125` 时开始（第二条特殊，等第一条画到 37.5% 才出现），20 条依次登场，球体是「一层层被画出来」的；
- **擦除加快半圈**：擦除阶段只占 0.5 个进度单位，比画出快一倍——消失得更干脆，视觉节奏更利落。

## 动态：传递式呼吸波浪

球体成形后不能是死板的——给它加呼吸感。但整组一起平移太僵硬，改成了**传递式波浪**：

- 每条椭圆独立浮动，带相位差 `i × 0.35 rad`；
- 波浪从第一个椭圆（左上端）传递到最后一个（右下端），像海浪扫过球面；
- 独立 `requestAnimationFrame` 驱动、时间驱动，**滚动停止也持续呼吸**，不跟滚轮绑定。

## 踩坑记录

1. **SVG 坐标偏移**：椭圆点坐标是相对圆心的（如 −141, −92），但 `translate` 是相对画布原点——不补上圆心偏移（375, 375），图形会被甩到画布外。圆点标记看得见、弧段看不见，排查了半天。
2. **anime.js 对象动画的 update 不可靠**：用 `animate({ v: 0 })` 驱动虚拟角度再在 update 里读值，页面里经常不触发/不写回，图形静止。最终改用 rAF 手动驱动——每帧按时间差推进角度，稳定可靠。
3. **dashoffset 的模长陷阱**：`dasharray = L L` 时 dash 段长等于整条路径，offset 怎么移都是「完整可见」，根本擦不掉。擦除必须让 offset 反向越过起点，或改用可见段 + 空白的分段画法。
4. **同角度扁椭圆 = 纺锤**：20 条椭圆如果同一个角度、固定扁度、沿一条线拉开，叠加出来只能是椭球/纺锤。球的错觉来自「大小渐变 + 位置错开 + 对称锚定」，方向不对时先检查这三点。

## 小结

这一段的本质是：**把「球」拆成一组带透视关系的椭圆，让它们随进度逐条画出来，再让它们整体呼吸**。视觉上的立体感，不来自任何一条线本身，而来自线条之间的大小、位置、时序关系。动画实验室后续的段位，会继续复用这套「参数化生成 + 进度驱动 + 独立动态」的骨架。

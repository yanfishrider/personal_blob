## 缘起

在 [chinese-independent-developer](https://github.com/1c7/chinese-independent-developer) 这个仓库里闲逛的时候，偶然看到一个四字母单词的阶梯谜题小游戏——[Poople](https://poople-game.com/)。规则很简单：给定一个起始单词和一个目标单词，每次只能改变一个字母，且每一步的结果都必须是合法单词，最终把起始单词一步步变成目标单词。

这其实就是经典的 Word Ladder 谜题——据说最早由刘易斯·卡罗尔（《爱丽丝梦游仙境》作者）发明。玩法纯粹但有深度，让人想一直试下去。当时就觉得这东西适合集成到自己的项目里，做一个更完善的版本。

## 在原有基础上的改进

原版的功能比较纯粹——就是阶梯变换本身。我打算在集成的同时加两个东西，让这个小工具更实用：

1. **单词翻译**：每变换出一个新单词，调用翻译 API 展示中文释义。光知道一个英文词不够，知道它是什么意思才有记忆点。
2. **例句展示**：每个单词附一条例句。上下文比孤立的释义更有助于理解，也增加了页面的信息密度。

从一个"拼字游戏"变成"拼字 + 学单词"的轻量工具，每变一个字母还能顺便学一个新词。

## 技术选型

翻译和例句数据来自第三方 API，前端用 Next.js 构建，核心流程：

```
用户输入单词 → 校验合法性（与上一步仅差一个字母）→ 调用词典 API → 返回翻译+例句 → 展示
```

几个关键点：

- **单词校验**：需要确保用户输入的词确实存在，且与上一个单词恰好相差一个字母。简单的客户端字符串对比 + API 兜底。
- **API 调用**：翻译和例句走同一个接口，减少请求次数。做好缓存，同一个单词不重复请求。
- **状态管理**：变换历史、当前单词、步数——用 React 状态就够了，不需要引入额外的状态库。

## 界面设计

布局保持简洁：顶部是目标单词和当前步数，中间是当前单词卡片（英文 + 中文释义 + 例句），底部是输入区和提交按钮。

视觉上延续了项目的整体风格，不做过度设计。当前单词与目标单词之间的差距用视觉提示展示——相同的字母高亮，不同的字母留空，让用户一目了然还有哪些字母需要变。

## 小结

本来只是 GitHub 上的随手一翻，结果变成了一个完整的 side project。过程中最大的收获不是代码本身，而是"看到一个好东西就想自己做一个更好版本"的冲动——这种冲动是开发者最好的驱动力。

## 缘起

笔记页的自定义徽章光标落地后，一直想验证一个"光标 + 打靶"的交互思路：光标不只是指针，而是像炮台一样自动转向最近的敌人，顶部指向目标，空格开火。于是在博客里单独开了一个 `/game` 页面来做这个试验。

## 玩法骨架

- **背景弹幕小球**：18 个彩色发光小球随机漂移，碰到边界反弹，纯氛围无威胁
- **伪 3D 黑柱**：6 根斜二测柱体散布在场地上，每根 4 点生命，打碎后原地重生一根，保持场上数量恒定
- **自动瞄准**：光标 300px 范围内锁定最近目标（球或柱），画虚线瞄准线 + 白色描边高亮
- **射击**：空格键发射发光白矩形子弹，带 110ms 连射冷却
- **命中反馈**：小球 1 发爆成彩色粒子；柱子命中闪白，碎裂时爆出 30+ 粒子

## 光标转向（炮台感的核心）

徽章光标不再固定朝向，而是**顶部始终指向最近的黑色柱体**：

```js
// 目标角度 = 柱子方位角 + 90°（让 -y 方向即"顶部"指向柱子）
var targetAngle = Math.atan2(bestP.cy - my, bestP.cx - mx) + Math.PI / 2;
// 平滑插值 + 角度环绕：转向走最短路径，不甩圈
var diff = targetAngle - curAngle;
while (diff > Math.PI) diff -= Math.PI * 2;
while (diff < -Math.PI) diff += Math.PI * 2;
curAngle += diff * 0.15;
```

两个关键点：

1. **旋转轴心 = 热点**：`transform-origin` 设为光标中心圆的位置（`HOT_X * SCALE`, `HOT_Y * SCALE`），这样无论转多少度，热点始终对准鼠标。
2. **translate 瞬时、rotate 平滑**：位置跟随由 mousemove 事件驱动，转向角度放在 rAF 主循环里做插值，视觉上光标"缓缓转头"而不是瞬移。

## 伪 3D 黑柱：斜二测画法

不引入 three.js，用 Canvas 2D 画斜二测（cabinet projection）柱体——底面中心向外偏移深度 `d`，顶面是底面整体上移 `h`：

```
右侧面（最深 #161616）→ 正面（#242424）→ 顶面（最亮 #343434）
```

三层填充 + 细白描边，立体感就有了。碰撞判定用柱体的 AABB（含高度），子弹点落在范围内即命中。

## 架构

- 页面最初是独立完整 HTML（不套布局），后改为套 `BaseLayout` 获得顶部导航栏
- 纯 `requestAnimationFrame` 游戏循环，`update()` + `render()` 分离
- 对象全部是普通数组（balls / pillars / bullets / particles），帧内倒序遍历避免 splice 越界
- 子弹碰撞循环内做球命中 → 柱命中 → 移除的短路逻辑

## 踩坑：canvas 定位错位导致"光标与弹幕不同步"

套 BaseLayout 重写页面时，漏掉了 `#game-canvas` 的 `position: fixed; top: 0; left: 0`。canvas 退回文档流 static 定位，左上角不再对齐视口原点（被导航栏压下去 56px、水平居中偏移）。

结果：游戏对象画在画布坐标、子弹从鼠标视口坐标发射，两套坐标系错位——**光标在鼠标位置，子弹却从偏移处射出**。

修复就是一行 CSS：把 canvas 钉回 `position: fixed`，画布 (0,0) 与视口 (0,0) 对齐，鼠标坐标直接可用。

## 效果

移动鼠标，徽章缓缓转向最近的柱子；空格连射，小球炸开彩色粒子、柱子碎裂重生。导航栏"游戏"入口可从任意页面直达。

后续可扩展：计分与关卡、柱子材质分层、ESC 暂停菜单、音效。
